# HTML Native Harness Rule

Use this rule for HTML-native visual production, multi-format prototypes, design variants, brand-asset protocol, or a bridge from visual exploration to PPT, image, or video output.

## Fused Reference

- Source: `alchaincyf/huashu-design`.
- Public snapshot: `not-bundled-snapshots/alchaincyf__huashu-design`.
- License status: permissive; upstream assets remain external references and are not NERO-owned.

## Use For

- HTML-native app or web visual prototypes.
- Multiple visual directions before choosing one.
- Brand asset intake: logo, colors, typography, screenshots, existing UI, and forbidden use.
- HTML visual QA before PNG/PDF/PPT-like export.
- Planning how a coded visual system becomes animated scenes.

## NERO Workflow

1. Route through NERO Design Team.
2. Define route, audience, format, size, tokens, brand assets, and evidence-bearing content.
3. Produce a small style matrix only when no direction is locked.
4. Use NERO tokens and project-local assets; do not copy upstream demos or media.
5. Build the chosen NERO-native artifact.
6. Run `visual-qa.md`; add `web-ppt.md` or `html-deck-style-discovery.md` when applicable.

## Variant Discipline

- Use two or three meaningfully different variants, not decorative permutations.
- Vary information hierarchy, density, typography rhythm, image treatment, or interaction model.
- Keep one shared content model so the comparison is about design rather than different arguments.
- Record the chosen direction and audience fit.

## Brand Asset Protocol

- Treat supplied brand assets as project-local unless explicitly promoted.
- Do not move client or project assets into `$NERO_DESIGN_TEAM_HOME/` by default.
- A reusable package needs a manifest recording source, allowed use, route, tokens, and review/expiry state.
- External images, audio, screenshots, and logos are reference-only unless separately licensed and approved.

## Hard Bans

- Do not enable TTS, audio generation, voice cloning, background music, or sound effects by default.
- Do not copy upstream media, HTML demos, watermarks, or asset folders.
- Do not add default watermarks unless requested.
- Do not write provider configuration or secrets.
- Do not treat generated images as carriers of exact text, financial data, tables, chart labels, source notes, or regulatory conclusions.

## Completion Gate

Report route and format, style-matrix use, tokens and brand assets, external-reference boundary, visual QA result, and unverified export or license risk.
