# 手写风格 / Editorial Handwritten Research Note

这是一个跨格式的 NERO-native 风格预设，不是独立 Skill，也不是一套可以覆盖内容、证据或正式交付规则的“皮肤”。

## 触发

用户说“手写风格”时，NDT Skill 解析为：

`editorial-handwritten-research-note@1.x`

随后按目标交付物加载对应适配器：

- 回复：结论先行、短句分行、少量标记和明确边界。聊天窗口不能保证真实手写字体或荧光背景。
- 研究图：使用确定性 HTML/CSS/SVG 或程序化排版；标题、正文、数字、坐标轴、柱形和曲线都进入手写视觉层，精确内容仍由确定性层承载。
- HTML / Web PPT：使用 CSS 变量、内联 SVG 和响应式重排，不把桌面画布机械缩小到手机。
- 正式 PPTX：由 Presentations 负责可编辑输出，标题、正文、图表和标注都必须保持可编辑。
- 前端 UI：只用于解释、引导或空状态，不把操作型 Dashboard 变成手绘海报。

## 核心语法

1. 先给判断，再给证据。
2. 一行只承载一个主要判断。
3. 标题、正文和数字共享同一手写节奏；中文可用确定性的逐字错位/轻微旋转补足字体环境差异。
4. 坐标轴、柱形和曲线使用手绘路径，但数据位置、单位、日期和来源必须可复核。
5. 黄色高亮只突出一个关键词、数字或方向。
6. 黑色圈线、下划线和删除线用于解释注意力，不用于制造证据。
7. 背景和纹理不能承载标题、数字、来源、图表或监管措辞。

## 使用边界

适合研究解释、公司/股票对比、产业机制、章节开场、结论页和轻量分析回复。

不适合监管申报页、密集投行附录、审计底稿表格、未核实数据、需要逐字严肃引用的正式正文，以及任何会让读者误以为“手写痕迹就是证据”的场景。

注册为 NDT 资产不等于新项目已经通过视觉 QA。每个项目仍需按目标画布、字体环境、移动端或投影环境和正式输出引擎重新验证。

## 不可变边界

- 不捆绑外部字体、图片、客户事实、项目标题、Logo、来源或截图。
- 不用图像生成模型写精确中文、金融数字、表格、坐标轴、来源或合规措辞。
- 正式 PPTX 不得用单张截图替代可编辑对象。
- 视觉样例冻结前，资产状态保持 `registered_working_reference`，不得标记为 `visual_ready`。
