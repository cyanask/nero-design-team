# 财经报纸调查风

## 适用范围

用于把一个金融或商业事件讲成可核验的调查式组图：先交代人物和利益关系，再按时间轴还原事件，随后解释杠杆、现金约束、风险定价和买方能力，最后收束到证据允许的结论。它适合基金出售、危机交易、资本重估和“谁在什么约束下做了什么”的事件题，不适合没有明确事件对象的泛泛行业盘点。

## 使用顺序

1. 进入 NDT `image-report / image-card-report` 路线，选择 `financial-broadsheet-investigative`。
2. 先冻结事件对象、时间范围、双方身份、硬数字和证据层级；再从 `layout-contract.json` 选择页面家族。
3. 通过 `tokens.css` 加载暖报纸底、墨黑、酒红、财经蓝、次级纸色和中西文字体层级。
4. 首图只承担“人物冲突＋一个硬数字”的点击承诺。人物照片默认只出现在首图，面积不超过画布 32%；内页改用报告封面、风险台、时间轴和机制图，避免重复人像。
5. 时间轴页必须在大字或副标题中写出事件主体；每个节点只写日期、动作和可验证结果，不把作者推断写成事实。
6. 杠杆与流动性页必须同口径、带期间和单位，使用三栏机制或双方能力对照；“收割”“操纵”“内幕”等定性词只有在一手证据明确支持时才可使用。
7. 两个平台共享事实顺序、Token 和页面任务，小红书可用更强的首图承诺，公众号可用更完整的事件摘要；不得为了平台差异改变事实口径。
8. 文字、数字、图表、日期和来源使用 HTML/CSS/SVG 确定性渲染。生成式图片只能承担无文字的氛围素材，不能生成精确文字、财务数字或证据图表。
9. 生成联系表，执行缩略图、顶部换行、溢出、重复人物、时间轴主体和证据边界检查；最后一页必须完成当前事件的因果收束，不写 `next issue` 或强行引导互动。

## 资产边界

- 本风格包不包含任何基金、公司、人物、文章数字、照片、文章标题或外部媒体 Logo。
- “财经报纸”“WSJ式”“Forbes式”只表示编辑语法参考，不得复制媒体 Logo、版头、专有字体、固定栏目名或页面截图。
- 人物图只承担识别，不承担事实证明；照片许可和人物身份必须回到项目证据包核验。
- 风格可以复用，事件结论不能复用。每个新项目必须重新建立事实表、时间轴、来源边界和反向证据。
